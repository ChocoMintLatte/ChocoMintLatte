### 🧑‍💻 About Me

- 🎓 **컴퓨터공학**을 전공하며 웹, 모바일 앱, 데스크톱 등 다양한 환경을 넘나들며 서비스를 직접 만들고 있습니다.
- 🎨 **프론트엔드(Frontend)와 UI/UX 설계**에 가장 큰 자신감과 흥미를 가지고 있으며, 부드러운 화면 인터랙션과 직관적인 사용자 경험을 구현하는 데 집중합니다.
- 🚀 최근에는 프론트엔드를 넘어 **FastAPI 백엔드 구축, AI 비전/음성 파이프라인 연동, 로컬·클라우드 DB 설계까지 End-to-End 풀스택 프로젝트**를 주도적으로 수행했습니다.
- 💡 프레임워크에만 의존하지 않고 **바닐라 웹 기술(Canvas, CSS, Web Audio)의 기본기**부터 **모던 크로스플랫폼 앱 아키텍처(Flutter + Riverpod)**까지 폭넓게 탐구합니다.
